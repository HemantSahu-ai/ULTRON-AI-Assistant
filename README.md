# ULTRON AI Assistant

A Python-based desktop AI assistant designed to combine AI-powered responses, task routing, desktop automation, web search, and voice interaction.

## Features

- Desktop graphical user interface built with PyQt5
- AI-powered conversational responses
- Intent classification and task routing
- Real-time web search
- Application and system automation
- Speech input and text-to-speech support
- Image-generation prompt handoff to external websites

## Tech Stack

- Python
- PyQt5
- Groq and Cohere APIs
- Speech and automation libraries
- Requests and BeautifulSoup

## Setup

1. Install Python 3.12.
2. Clone or download this repository.
3. Create and activate a virtual environment.
4. Install dependencies:

   `python -m pip install -r Requirements.txt`

5. Create a local `.env` file with the API keys required by your configuration.
6. Run `Main.py`.
